Netris Controller is installed as a Kubernetes application on dedicated bare-metal hosts.

<Note>
  Select ONE installation option below.
</Note>

- [Installing HA Netris Controller in Air-Gapped Environments](/4.17/installation/controller-k3s-air-gap-ha) — install the Netris Controller as a highly-available VM-based deployment, including in air-gapped environments.
- [Helm Chart Installation](/4.17/installation/controller-k8s-installation) — deploy the Netris Controller as a Kubernetes application using the official Helm chart.
- [Zero Touch Provisioning (ZTP)](/4.17/installation/ztp) — automatically provision and onboard switches once the controller is installed.

See [General Settings](/4.17/general-settings) for the controller-wide settings under Settings → General.
